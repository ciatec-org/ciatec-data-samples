1. Desempenho do Participante por Grupo Clínico

  • Caso de Uso no Jogo Sério: Avaliar e comparar a taxa média de acerto (hitRate) de jogadores do grupo com Paralisia Cerebral (CP) versus o grupo controle (Control).

Code snippet
SELECT ?group (COUNT(DISTINCT ?participant) AS ?totalParticipants) (AVG(?hitRate) AS ?avgHitRate)
WHERE {
  ?participant a ex:Participant ;
               ex:studyGroup ?group ;
               ex:hasMatch ?match .
  
  ?match a ex:Match ;
         ex:hitRate ?hitRate .
}
GROUP BY ?group
ORDER BY DESC(?avgHitRate)

2. Análise de Precisão de Arremessos em Partidas Específicas

  • Caso de Uso no Jogo Sério: Contar quantos arremessos foram acertos (isHit = true) versus erros (isHit = false) dentro de partidas jogadas por um determinado participante.

Code snippet
SELECT ?match ?isHit (COUNT(?shot) AS ?totalShots)
WHERE {
  ?participant a ex:Participant ;
               schema:identifier 32 ;
               ex:hasMatch ?match .
  
  ?match ex:hasShot ?shot .
  ?shot a ex:ShotAttempt ;
        ex:isHit ?isHit .
}
GROUP BY ?match ?isHit
ORDER BY ?match

3. Adaptação Dinâmica de Dificuldade (DDA - Dynamic Difficulty Adjustment)

  • Caso de Uso no Jogo Sério: Identificar jogadores que estão apresentando baixa taxa de acerto (hitRate < 0.30) nas partidas para ajustar o nível de dificuldade do jogo em tempo real.

Code snippet
SELECT ?participant ?participantID ?match ?hitRate
WHERE {
  ?participant a ex:Participant ;
               schema:identifier ?participantID ;
               ex:hasMatch ?match .
  
  ?match ex:hitRate ?hitRate .
  
  FILTER(?hitRate < 0.30)
}
ORDER BY ?hitRate

4. Extração da Ontologia (Metadados de Classes e Propriedades)

  • Caso de Uso no Jogo Sério: Consultar a estrutura do modelo conceitual diretamente do endpoint SPARQL para motor de regras semânticas do jogo.

Code snippet
SELECT ?class ?label ?parentClass
WHERE {
  ?class a owl:Class ;
         rdfs:label ?label .
  OPTIONAL { ?class rdfs:subClassOf ?parentClass . }
}
